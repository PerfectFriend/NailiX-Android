## 🧅 2. РУКОВОДСТВО ПО НАСТРОЙКЕ ONION НОДЫ НА BEELINK SER 9 (ИЛИ ДРУГОМ МИНИ-ПК)

Для организации локального хостинга проекта на мини-компьютере во время разработки и подготовки к суверенному релизу настройте серверную ноду через Tor.

### Шаг 1. Подготовка ОС (Debian / Ubuntu) на Beelink SER 9
Установите последнюю версию Debian Stable или Ubuntu Server LTS. Убедитесь, что установлены утилиты `curl`, `git` и `docker`:
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl git docker.io docker-compose tor
```

### Шаг 2. Развертывание локального бэкенда (`server_node`)
Скопируйте папку `/server_node` на ваш Beelink SER 9. Перейдите в неё и запустите Node.js сервер (или соберите Docker-контейнер):
```bash
cd server_node
npm install
npm start
```
По умолчанию сервер запустится на порту `3000`.

### Шаг 3. Конфигурация Скрытого Сервиса Tor (Onion Service)
Отредактируйте конфигурационный файл Tor `/etc/tor/torrc` для маршрутизации внешних запросов с onion-адреса на ваш локальный бэкенд:
```bash
sudo nano /etc/tor/torrc
```
Добавьте следующие строки в раздел скрытых сервисов:
```text
############### This section is just for Onion Services ####################

HiddenServiceDir /var/lib/tor/nailhub_service/
HiddenServicePort 80 127.0.0.1:3000
```
Сохраните изменения и перезапустите Tor:
```bash
sudo systemctl restart tor
```

### Шаг 4. Получение публичного адреса `.onion`
Для получения сгенерированного приватного адреса вашей ноды выполните команду:
```bash
sudo cat /var/lib/tor/nailhub_service/hostname
```
Вы увидите строку вида `xyzw123...abc.onion`. Этот адрес теперь работает как глобальный домен вашей ноды, доступный из Android-приложения через прокси/клиент Tor (или Orbot) без белого IP и проброса портов!

## 📯 3. ТРАНСПОРТНЫЙ УРОВЕНЬ SIMPLEX MQ (АНОНИМНОСТЬ И СУВЕРЕННОСТЬ)

**SimpleX MQ** — это первый протокол связи, который не имеет постоянных идентификаторов пользователей (даже хэшированных), гарантируя полную защиту метаданных. 

### Концепция интеграции Simplex в приложение:
* Клиентское приложение шифрует данные бронирования с использованием открытого ключа мастера (AES-256-GCM + Curve25519) и отправляет их в однонаправленную очередь Simplex MQ мастера.
* Нода мастера на Beelink SER 9 периодически опрашивает входящие очереди Simplex через WebSocket/HTTP API, расшифровывает транзакции и записывает их в локальную БД.

### Архитектура очередей сообщений:
```text
[ Клиент (Android App) ]
        │
        ▼ (Шифрование Curve25519 + AES)
[ SimpleX MQ Сервер (Транзит) ]  <─── (Передача через шифрованные очереди)
        │
        ▼ (WebSocket / Long Polling)
[ Нода Мастера (Beelink SER 9) ] ───► Запись в db.json и синхронизация
```

В каталоге `/app/src/main/java/com/example/data/` подготовлены базовые модели для интеграции транспорта. OpenCode должен продолжить доработку WebSocket-подключения к серверам очередей Simplex (например, к публичным серверам `smp://...`).

## 📊 4. БИЗНЕС-МОДЕЛЬ ДЛЯ МИНИ-ПК С ОКУПАЕМОСТЬЮ ДО 18 МЕСЯЦЕВ

Чтобы стимулировать владельцев нод держать физические мини-ПК Beelink SER 9 (Ryzen 9, 32GB RAM, 1TB SSD), заложена экономическая модель:
1. **Shared Hosting для Мастеров:** Одна нода Beelink на домашнем гигабитном канале может обслуживать до 20 независимых мастеров в городе. При подписке в $5/мес доход составит `$100/мес`.
2. **Локальный ИИ-Генератор (GPU/NPU Offloading):** Мини-ПК генерирует варианты дизайна ногтей локально (через Stable Diffusion), экономя затраты на внешние API. Списание $0.05 за генерацию приносит еще `~$15/мес`.
3. **P2P Резервное копирование:** Предоставление шифрованного хранилища под бэкапы других нод дает еще `~$10/мес`.
* **Итог:** Капитальные затраты на мини-ПК (~$800) окупаются менее чем за **9-12 месяцев**, обеспечивая стабильный пассивный доход владельцу ноды!
